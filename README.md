# 🍕 Pizza Menu

A React learning project built to practice React components and create a simple pizza menu interface.

## 📌 About the Project

Pizza Menu is a frontend project for practicing React fundamentals through a menu-based application.

## 🛠️ Technologies

- React
- JavaScript
- HTML
- CSS

## 🎯 Learning Goals

- Understand how React components structure a user interface.
- Practice organizing UI into reusable components.
- Strengthen JavaScript and React fundamentals.

## 🚀 Getting Started

1. Clone this repository.
2. Open the project folder in your terminal.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```

5. Open the local URL shown in your terminal.
